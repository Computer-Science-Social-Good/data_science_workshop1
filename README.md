# Intro to Data Science & Basic Machine Learning

A beginner-friendly workshop hosted by **CS+Social Good at the University of Delaware**.

This workshop introduces the fundamentals of data science, including data cleaning, exploratory data analysis, feature selection, and basic machine learning models.

## Workshop Overview

We'll use a simulated bike rental dataset to explore the data science pipeline and answer two questions:

- Can we predict whether a day will be busy?
- Can we predict how many bikes will be rented?

We'll explore three machine learning models: K-Nearest Neighbors (KNN), Decision Trees, and Linear Regression.
